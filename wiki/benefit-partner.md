# Benefit / Partner (GraphQL read)

Collection `partners` — partner benefits and discount codes. Read-only via [[graphql]].
Fields verified against the GraphQL SDL. Source: Swagger *Kilocal App*.

## Layout

- **Hero partner:** `main_partner: true`
- **Secondary list:** `main_partner: false`

## Fields (`partners` type)

| Field | Type | Notes |
|-------|------|-------|
| `id` | ID | |
| `name` | String | |
| `coupon` | String | discount code |
| `logo` | directus_files | |
| `asset` | directus_files | |
| `main_partner` | Boolean | hero vs list |
| `cta_brand` | links | external CTA |
| `translations` | [partners_translations] | `description`, `coupon_instructions` |

## Query

```graphql
query GetPartners($filter: partners_filter) {
  partners(filter: $filter, sort: ["name"]) {
    id
    name
    coupon
    main_partner
    logo { id }
    asset { id }
    cta_brand { id url }
    translations { languages_code { code } description coupon_instructions }
  }
}
```

## Resolves missing-apis §6

Replaces the proposed `GET /api/benefits` / `/redeem` in [[missing-apis]] §6. The coupon code
is a field on `partners` (`coupon`), not generated by a redeem endpoint.

  `status` (`active`/`past`/`coming_soon`) oppure `date_start`/`date_end`. Vedi [[missing-apis]].
